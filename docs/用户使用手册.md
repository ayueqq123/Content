# TG Bot Desktop 用户使用手册

## 一、软件简介

TG Bot Desktop 是一款 Windows 桌面工具，通过 Telegram Bot 引导用户完成账号登录流程。软件已编译为独立 `.exe` 文件，**无需安装 Python 或任何依赖**，双击即可运行。

---

## 二、系统要求

- **操作系统**: Windows 10 / 11（64 位）
- **网络**: 需要能访问 Telegram 服务器（如无法直接访问需配置代理）
- **其他**: 无需安装 Python、无需安装其他软件

---

## 三、获取软件

### 方式一：从 GitHub Actions 下载（日常构建）

1. 打开 GitHub 仓库 → 点击顶部 **Actions** 标签
2. 选择最新一次成功的 **Build TGBot.exe** 运行
3. 在页面底部 **Artifacts** 区域点击 **TGBot-windows** 下载
4. 解压得到 `TGBot.exe`

### 方式二：从 Releases 下载（正式版本）

1. 打开 GitHub 仓库 → 点击右侧 **Releases**
2. 找到最新版本，点击 `TGBot.exe` 下载

---

## 四、首次启动 — 卡密激活

1. 双击 `TGBot.exe` 启动软件
2. 首次运行会弹出 **卡密激活** 窗口
3. 窗口中显示你的 **机器码**（HWID），格式如 `XXXX-XXXX-XXXX-XXXX`
4. 在输入框中填入管理员提供的 **卡密**（如 `TG-ABCD1234-30D`）
5. 点击 **激活** 按钮
6. 激活成功后进入主界面

> **注意**: 卡密与机器绑定，换电脑需要新卡密。卡密过期后需重新激活。

## 六、配置说明

### 6.1 Bot 设置（必填）

| 配置项 | 说明 | 获取方式 |
|--------|------|----------|
| **Bot Token** | Telegram Bot 的认证令牌 | 找 @BotFather → /newbot → 复制 Token |
| **API ID** | Telegram 应用 ID | 访问 https://my.telegram.org → API Development |
| **API Hash** | Telegram 应用密钥 | 同上，与 API ID 一起获取 |
| **代理** | 网络代理（可选） | 见下方代理格式说明 |
| **输出目录** | Session 文件保存路径 | 默认为 `accounts` 文件夹 |
| **设备名称** | 登录显示的设备名 | 默认 `Desktop Client` |

### 6.2 代理格式

如果你的网络无法直接连接 Telegram，需要配置代理。支持以下格式：

```
socks5://IP:端口
socks5://用户名:密码@IP:端口
http://IP:端口
IP:端口:用户名:密码      ← 自动识别为 SOCKS5
```

**示例**:
```
socks5://127.0.0.1:1080
192.168.1.1:1080:admin:pass123
```

### 6.3 回复配置

自定义 Bot 发送给用户的所有文案：

- **欢迎语**: 用户发 /start 后看到的消息
- **手机号提示**: 提示用户提供手机号
- **验证码提示**: 提示用户输入验证码（回执码）
- **两步验证提示**: 提示输入两步验证密码
- **成功提示**: 登录成功后的消息
- **错误提示**: 各类错误的提示消息
- 更多字段可在界面中查看和修改

### 6.4 登录成功配置

配置登录成功后的自动操作：

- **成功消息**: 登录成功后发送的文本
- **发送图片**: 可选，成功后发送一张图片
- **群转发**: 可选，将结果转发到指定群
- **自动回复**: 可选，设置自动回复消息

## 七、使用流程

### 7.1 启动 Bot

1. 确保已填写 **Bot Token**、**API ID**、**API Hash**
2. 点击控制栏的 **▶ 启动Bot** 按钮
3. 等待日志显示 `Bot 已连接: @你的Bot用户名`
4. 状态栏变为绿色 "运行中"

### 7.2 Bot 工作流程（自动模式）

Bot 启动后，当有用户与你的 Bot 交互时：

```
用户 → /start → Bot 显示「开始恢复账户」按钮
用户 → 点击按钮/分享联系人 → Bot 发送验证码到该手机号
用户 → 输入「TG+验证码数字」 → Bot 尝试登录
     → 如需两步验证 → Bot 提示输入密码
     → 登录成功 → Session 保存到输出目录
```

### 7.3 手动登录

如果需要手动登录（不通过 Bot 交互）：

1. 点击控制栏的 **手动登录** 按钮
2. 在弹窗中输入手机号（含国际区号，如 `+8613800138000`）
3. 点击 **发送验证码**
4. 输入收到的验证码
5. 如有两步验证，输入密码
6. 登录成功，Session 文件保存到输出目录

### 7.4 停止 Bot

- 点击控制栏的 **■ 停止** 按钮即可停止 Bot

---

## 八、Session 文件

- 登录成功后，Session 文件保存在 **输出目录**（默认 `accounts/`）
- 文件名格式：`手机号.session`
- 每个 Session 代表一次成功登录

## 九、常见问题

### Q: 启动后提示 "未配置 Bot Token"
**A:** 在 "Bot设置" Tab 中填入 Bot Token 后重试。

### Q: 提示 "API_ID/API_HASH 未配置"
**A:** 前往 https://my.telegram.org 获取 API ID 和 API Hash，填入 "Bot设置" Tab。

### Q: 提示 "Bot Token 无效 (Unauthorized)"
**A:** Token 错误或已被撤销。去 @BotFather 检查或重新生成 Token。

### Q: 提示 "网络请求失败"
**A:** 检查网络连接和代理设置。确保能访问 Telegram 服务器。

### Q: 验证码发送失败 / 提示 "请求过于频繁"
**A:** Telegram 有频率限制。等待提示的秒数后重试。

### Q: 卡密提示 "已过期"
**A:** 联系管理员获取新的卡密。

### Q: 换了电脑后卡密无法使用
**A:** 卡密绑定了机器码（HWID），换电脑需要新的卡密。

### Q: 杀毒软件报警
**A:** Nuitka 编译的 .exe 可能被误报。请添加白名单或关闭实时防护后运行。

## 十、注意事项

1. **保持网络稳定** — Bot 运行期间需要持续网络连接
2. **不要频繁发送验证码** — Telegram 有频率限制，频繁操作可能被暂时封禁
3. **妥善保管卡密** — 卡密与机器绑定，丢失无法找回
4. **定期检查更新** — 从 GitHub Releases 下载最新版本获取修复和新功能
5. **杀毒白名单** — 首次运行建议将 `TGBot.exe` 加入杀毒软件白名单
