========================================
    TG Bot Desktop 使用手册
========================================

【软件简介】

这是一款 Windows 桌面工具，用来运行 Telegram Bot 自动引导用户完成账号恢复流程。
软件已经打包成一个 .exe 文件，不需要安装任何东西，双击就能用。


========================================
一、下载和安装
========================================

1. 从管理员那里获取 TGBot.exe 文件
2. 放到电脑任意位置（建议桌面或单独建一个文件夹）
3. 双击运行即可

注意：
- 不需要安装 Python
- 不需要安装任何其他软件
- 如果杀毒软件报警，添加白名单即可（软件是安全的）
- 系统要求：Windows 10 或 Windows 11（64位）


========================================
二、首次使用 — 卡密激活
========================================

第一次打开软件会弹出激活窗口：

1. 窗口里会显示你的"机器码"（一串字母数字）
2. 把机器码发给管理员，管理员会给你一个"卡密"
3. 把卡密粘贴到输入框里
4. 点"激活"按钮
5. 提示激活成功后就进入主界面了

注意：
- 卡密和电脑绑定，换电脑需要找管理员要新卡密
- 卡密有有效期，过期后需要重新激活


========================================
三、开始前的准备工作
========================================

使用软件前，你需要准备以下信息：

【必须准备的】

1. Bot Token（机器人令牌）
   - 打开 Telegram，搜索 @BotFather
   - 发送 /newbot，按提示创建一个机器人
   - 创建成功后会给你一串 Token，类似：
     123456789:ABCdefGHIjklMNOpqrsTUVwxyz
   - 复制这个 Token

2. API ID 和 API Hash
   - 用浏览器打开 https://my.telegram.org
   - 用你的 Telegram 手机号登录
   - 点 "API development tools"
   - 填写应用名称（随便写），点创建
   - 记下 App api_id（一串数字）和 App api_hash（一串字母数字）

【可选准备的】

3. 代理（如果你的网络不能直接连 Telegram）
   格式举例：
   - 127.0.0.1:1080（最简单的格式，IP:端口）
   - 127.0.0.1:1080:用户名:密码（带账号密码的）
   - socks5://127.0.0.1:1080（完整写法）


========================================
四、软件设置
========================================

主界面上方有三个标签页：Bot设置、回复配置、登录成功配置


--- 4.1 Bot设置（必须填的） ---

Bot Token：     填你从 BotFather 拿到的 Token
API ID：        填你从 my.telegram.org 拿到的数字
API Hash：      填你从 my.telegram.org 拿到的字母数字串
代理：          如果需要代理才能连 Telegram，填代理地址
输出目录：      登录成功的 session 文件保存位置，默认是 accounts 文件夹

Token 文件：    【多Bot批量运行用】
                如果你有多个 Bot 要同时运行，创建一个 txt 文件，
                每行写一个 Bot Token，然后选择这个文件。
                软件会同时启动所有 Bot。

Bot 昵称：      填了的话启动时会自动设置 Bot 的显示名称
Bot 头像：      选择一张图片，启动时自动设置为 Bot 头像
                （注意：头像设置可能不生效，需要通过 @BotFather 手动设置）

健康检测：      勾选后 Bot 会定时检查自己是否在线
检测间隔：      多少秒检查一次（默认180秒=3分钟）


--- 4.2 回复配置 ---

这里设置 Bot 自动发给用户的各种消息内容。

欢迎语（start_text）：
    用户发 /start 后看到的第一条消息

默认回复（default_reply）：
    用户随便发消息（不在流程中）时的自动回复

/start 催促（start_no_response_text）：
    用户点了 /start 但迟迟不操作时，发送催促消息
    催促等待时间：多少秒后发催促（默认45秒）
    催促次数：最多催促几次（默认1次）

欢迎按钮：
    勾选"启用欢迎按钮"后，/start 时会额外显示一个可点击的链接按钮
    按钮文字：按钮上显示什么字
    按钮链接：点击后打开什么网页

验证码相关文案：
    验证码发送提示、格式错误提示、错误次数提示等
    都可以自定义修改

两步验证相关文案：
    密码提示、密码错误提示等

自动回复设置：
    当用户在输入验证码/密码阶段长时间不回复时，自动发送催促消息
    间隔（分钟）：每隔多久发一次（默认1分钟）
    最多发几次：默认3次
    自动回复1/2/3：三次催促各自的内容


--- 4.3 登录成功配置 ---

成功提示（success_text）：
    登录成功后发给用户的消息

发送图片：
    勾选后登录成功时会额外发一张图片
    图片路径：选择本地图片文件

显示12位标识：
    勾选后发送验证码时会附带一个随机12位标识码
    （纯展示用，让界面看起来更专业）

上传到群（success_group_id）：
    填写 Telegram 群/频道的 ID（数字，通常是负数如 -1001234567890）
    登录成功后会自动把 session 文件上传到这个群
    群密码：上传时附带的备注密码

延迟检测（post_login_check_delay）：
    登录成功后等多少秒再检查 session 是否有效（默认86秒）
    检测结果会发给用户

USDT地址提取：
    勾选后会自动扫描用户发过的消息，提取加密货币钱包地址
    支持：TRC20/USDT、ERC20/ETH、BTC 地址
    提取到的地址会发送给用户，也会发到配置的群


========================================
五、启动和运行
========================================

--- 5.1 启动 Bot ---

1. 确认 Bot Token、API ID、API Hash 都填好了
2. 点击界面下方的【启动 Bot】按钮
3. 看底部日志区域，出现"Bot 已连接: @xxx"说明启动成功
4. 如果用了 Token 文件，日志会显示多个 Bot 连接成功

启动后 Bot 就在自动运行了，不需要做其他操作。


--- 5.2 Bot 自动工作流程 ---

当有人给你的 Bot 发消息时，流程如下：

  用户发 /start
    ↓
  Bot 显示欢迎语 + "开始恢复账户"按钮
    ↓
  用户点按钮
    ↓
  Bot 提示用户手动输入手机号（要带区号，比如 +86 13088888888）
    ↓
  用户输入手机号（输错可重试，超过次数提示本轮已结束需重新开始）
    ↓
  Bot 发送验证码到这个手机号
    ↓
  Bot 提示用户输入回执码（格式：TG + 数字）
    ↓
  用户输入回执码
    ↓
  如果需要两步验证 → Bot 提示输入密码
    ↓
  登录成功 → session 文件保存到输出目录

整个过程全自动，你只需要看日志了解进度。


--- 5.3 手动登录 ---

如果你想手动操作（不通过 Bot 交互）：

1. 点击【手动登录】按钮
2. 输入手机号（要带区号，比如 +8613800138000）
3. 点"发送验证码"
4. 输入收到的验证码
5. 如果有两步验证，输入密码
6. 完成后 session 保存到输出目录


--- 5.4 手动聊天回复 ---

点击【显示手动回复/聊天】可以展开聊天面板：
- 左边：显示所有跟 Bot 交互过的用户列表
- 右边：选择一个用户后显示对话记录
- 底部：可以直接输入消息手动回复给用户


--- 5.5 停止 Bot ---

点击【停止】按钮即可停止所有 Bot。


========================================
六、Session 文件说明
========================================

- 登录成功后会生成 .session 文件
- 默认保存在软件目录下的 accounts 文件夹里
- 文件名是手机号，如：8613800138000.session
- 这个文件就是登录凭证，妥善保管


========================================
七、常见问题
========================================

问：启动后提示"未配置 Bot Token"
答：在 Bot设置 里填入 Token 再启动。

问：提示"API_ID/API_HASH 未配置"
答：去 https://my.telegram.org 获取，填到 Bot设置 里。

问：提示"Bot Token 无效 (Unauthorized)"
答：Token 错了或被撤销了。去 @BotFather 用 /mybots 检查，
    或者用 /deletebot 删掉重新 /newbot 创建。

问：提示网络错误 / 连接超时
答：可能是网络不能直接连 Telegram。配置代理试试。

问：验证码发送失败 / 提示请求过于频繁
答：Telegram 有限制，操作太快会被临时限制。等几分钟再试。

问：卡密过期了怎么办
答：联系管理员获取新卡密重新激活。

问：换了电脑，卡密用不了
答：卡密绑定电脑，换电脑需要找管理员要新卡密。

问：杀毒软件一直报警
答：把 TGBot.exe 加入杀毒白名单。
    设置方法：杀毒软件 → 设置 → 白名单/排除项 → 添加文件 → 选择 TGBot.exe

问：Bot 启动成功但用户发消息没反应
答：检查是否有其他地方也在运行同一个 Bot Token（同一个 Token 只能一个地方运行）。
    先停止其他地方的，再重新启动。

问：多个 Bot 同时运行，部分启动失败
答：日志里会显示哪些成功哪些失败。检查失败的 Token 是否正确。
    成功的 Bot 会正常运行不受影响。

问：session 文件在哪里
答：默认在软件同目录的 accounts 文件夹。
    也可以在 Bot设置 的"输出目录"里改成其他位置。


========================================
八、注意事项
========================================

1. 保持网络稳定 — Bot 运行期间要一直有网
2. 不要太频繁操作 — Telegram 有频率限制，太快会被封一段时间
3. 保管好卡密 — 丢了找管理员重新要
4. 定期更新软件 — 有新版本及时更新
5. 一个 Token 只在一处运行 — 同一个 Bot Token 不要两个地方同时用
6. 杀毒白名单 — 首次使用建议把软件加入白名单
